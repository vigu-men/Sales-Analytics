# Sales-Analytics
##Description
This SQL project calculates the cumulative revenue achievement against cumulative revenue targets on a daily basis.
## Task 
Calculate the percentage of cumulative revenue achieved compared to cumulative revenue targets for each day.
##Tools
- SQL
- Google BigQuery
## SQL Concepts Used
- UNION ALL
- JOIN
- Aggregate Functions
- Window Functions
- GROUP BY
- ORDER BY
## Result
The query returns:
- Date
- Cumulative revenue
- Cumulative revenue target
- Percentage of target achieved
